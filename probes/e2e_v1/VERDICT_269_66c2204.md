## P1 SCOPE-1 — envelope path matcher has no path boundary
`envelope_scope.path_in_authorized_scope` (copied from `workforce.authority.path_allowed`) does two things wrong:
- it ends with `if normalized.startswith(prefix): return True`;
- it normalizes with `path.lstrip("./")`, which removes any leading dots and slashes, not just a `./` prefix.

Matcher results:
- With envelope `["backend/app/greeting.py", "backend/tests/test_greeting_doc.py"]`, all of these return True: `backend/app/greeting.py_backdoor.py`, `.backend/app/greeting.py`, `backend/tests/test_greeting_doc.py.d/x.py`.
- With `["backend/app/mainai_execution"]`, `backend/app/mainai_execution_evil.py` is in scope.

End to end:
- the planner declared `backend/app/greeting.py_backdoor.py`;
- the code agent wrote it;
- it was **committed, pushed** (`git diff base..branch` = `backend/app/greeting.py_backdoor.py`, `backend/tests/test_greeting_doc.py`), and a **draft PR was opened**;
- there were no refusals.

**Fix:** exact match, or a directory prefix only when the authorized entry ends in `/` (or `/**`), with a component boundary. Normalize only a literal leading `./`, and reject `.`-prefixed variants. Do not reuse the workforce matcher as is; that function has the same flaw and is worth a separate ticket.

## P1 CAP-1 — `repo_edit` implies `open_pr`
`OPEN_PR_CAPABILITIES = {"open_pr", "create_pr", "repo_edit"}`. An envelope with `[path_a, read_file, repo_edit, run_tests]` (no `open_pr`) still opened a draft PR, and `open_pr` completed. Publication is an outward action the Founder must grant explicitly.

**Fix:** `{"open_pr", "create_pr"}` only. If the coupling is intended, the Founder must decide it and document it.

## P2 FC-2b — CTX gate still trusts prose
`prepare_code_agent_prompt` builds `explicit_paths` from the description text plus the declared targets. For envelope-governed goals, use only the declared `Target files:` (and mapped tests) as write authority. Prose may still be shown for context but must not authorize writes. The impact is bounded by the envelope paths, which is why this is P2.

## P2 ROUTE-4 — Supervisor in-flight overlap on an envelope switch
`path_a_dispatch_is_authorized` should also require that no active, unexpired `supervisor_goal_leases` row exists for the goal. Alternatively, the Supervisor lease release could gate Path A dispatch.

## Minor
- `finalize` checks the model-reported `files`, not the actual commit diff (`git diff --name-only base..HEAD`). The salvage path commits with `git add -A` and falls back to declared targets. Checking the real diff against the envelope before the push would close this defence-in-depth gap.
- `READ_CAPABILITIES` includes `path_a`, so any `path_a` envelope allows `read_only_audit` (an AI call with no repo access). This is acceptable, but should be documented.
